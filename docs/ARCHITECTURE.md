# Arquitetura do Projeto (camadas de desenvolvimento)

## Front-End

Vamos utilizar as seguintes bibliotecas principais:
- TypeScript: Lingaguem principalmente de desenvolvimento com tipagem
- Next.js: Framework para criação e gestão de interfaces
- React.js: Biblioteca para criação e componenticação de interfaces
- Biome: Validação/formatação/correção de códigos (lint)
- TailwindCSS: Estilização
- Date-FNS: Manipulação de data/hora
- Shadcn: Componenticação base (design system)
- React Query: Criação e gestão de queries para ler dados da API e mutations para alterar dados.

## Back-End

Vamos utilizar as seguintes bibliotecas principais:
- TypesScript: Lingaguem principalmente de desenvolvimento com tipagem
- Next.js: Framework para criação e gestão de APIs
- Bcryptjs: Geração de salt + hash da senha (https://www.npmjs.com/package/bcryptjs)
- Mastra.ai: Criação e customização de agentes internos
- TRPC: Gestão de endpoints

## Banco de dados

- Supabase: PostgreSQL

## Infraestrutura

- Vercel: Hospedar tanto o servidor (API) quanto cliente (SPA)

## Automação

- N8N: Criação de fluxos automatizados
